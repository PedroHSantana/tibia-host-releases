# TibiaPK Tools Host — instaladores

Este repositório guarda só os instaladores do TibiaPK Tools Host (Windows).
O código fica em um repositório privado.

- Baixe o `TibiaPK-Host-Setup-<versão>.exe` da versão mais recente em **Releases**.
- Para enviar dados ao site, o host precisa do `host-config.txt` fornecido em particular pelo operador (ao lado do instalador).
- O app instalado verifica sozinho se há versão nova (`latest.json`).
